Privacy Policy - Claude YouTube Agent

Last updated: October 24, 2026

Who uses this app

Claude YouTube Agent is a personal tool used only by the owner of the YouTube channel "Muhammad Ramzan Ali". It is not offered to the public.

What data it accesses

With the owner's Google OAuth consent, the app accesses the owner's YouTube channel through Google's official APIs: channel and video details, playlists, comments, captions, and YouTube Analytics and revenue reports. It can upload or update videos, thumbnails, playlists and comments only when the owner asks it to.

How data is stored and used

  • The OAuth token is stored only on the owner's own computer.
  • YouTube data is used only to answer the owner's requests inside the Claude Desktop app.
  • No data is sold, shared with third parties, or used for advertising.
  • The app does not run on any server of its own.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions, and the local token can be deleted from the owner's computer.
