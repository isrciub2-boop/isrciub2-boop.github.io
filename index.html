Claude YouTube Agent

Claude YouTube Agent is a private, personal tool that lets the owner of the YouTube channel "Muhammad Ramzan Ali" manage that channel with the Claude Desktop app on their own computer.

It uses the official YouTube Data API, YouTube Analytics API and YouTube Reporting API, through Google OAuth, to read channel analytics, manage videos, playlists and comments, and plan content.

It is not a public service and is not offered to other users.
